# ForeverTweaks

Personal tweaks addon for **World of Warcraft: Forever** (Interface 16001). It started as **QuestFilter**, a vanilla-quest auto-accepter, and grew into the place where every small fix and one-time setup for my UI lives.

Main character: Ruzangrad (Human Retribution Paladin). Alt: Bankstander.

## Install

The live addon folder is a junction to this repository, so edits here are what the game loads:

```powershell
New-Item -ItemType Junction -Path "C:\Program Files (x86)\World of Warcraft\_forever_\Interface\AddOns\ForeverTweaks" -Target "C:\Users\m_ren\repos\ForeverTweaks"
```

Then enable **ForeverTweaks** in the AddOns list at character select. A new addon folder needs a full game restart; code changes only need `/reload`.

## Commands

| Command | Old alias | What it does |
|---|---|---|
| `/ft` | | Lists the commands |
| `/ftquests` | `/qf` | Turns vanilla quest automation on or off |
| `/ftlayout` | `/qflayout` | Re-applies the HUD layout (Edit Mode plus addon positions), then `/reload` |
| `/ftparty` | `/qfparty` | Re-applies the party frame layout |
| `/ftdump` | `/qfdump` | Saves Edit Mode systems, enums and frames near screen center into `ForeverTweaksDB.dump` (`/reload` writes it to disk) |

All layout commands refuse to run in combat.

## Features

### Vanilla quest automation

- Quests whose ID is in `ForeverTweaksVanilla` (`VanillaIDs.lua`) are accepted and turned in automatically, from gossip and quest dialogs.
- New Forever quests are left alone so they can be read (in Immersion).
- Rewards are only taken automatically when there is at most one choice.
- Hold **Shift** at the NPC to handle a quest by hand. `/ftquests` toggles it.
- `VanillaIDs.lua` is generated by `update_ids.py` (see Maintenance).

### Macros

On every login it creates any missing account macros and resets their icons:

| Macro | Purpose |
|---|---|
| Attack | `/startattack` (Ashbringer icon) |
| HS Downrank | Holy Strike rank 2, rank 1 with Ctrl (Crusader Strike icon) |
| Seal Downrank | Seal of the Crusader rank 1 |
| Judge Twist | Judgement, then Crusader with Ctrl or Righteousness with Shift |
| Heal Self | Holy Light; Flash of Light with Shift; mouseover, target or self |
| HoJ Stop | Stopcast plus Hammer of Justice (mouseover first) |
| Blessing | Might; Kings with Shift; Wisdom with Ctrl |
| RF Toggle | Righteous Fury on; Shift cancels it |
| Bubble Hearth | Divine Shield or Divine Protection, then Hearthstone |
| Heal Pot / Healthstone | Best potion or healthstone in the bags |
| Sit, Big Plates, Big Chat | Utility |

The FTA Target macro (from Follow The Arrow) gets a fixed icon.

### Minimap icons

Leatrix Plus hides LibDBIcon minimap buttons until you hover over the minimap. Some addons use custom buttons it cannot hide. ForeverTweaks hides each original button and registers a standard LibDBIcon launcher in its place (prefix `QF_`). Positions are saved in `ForeverTweaksDB.icons`.

- Widsith
- Pally Seal Cooldowns
- One Key Fishing
- LootGoblin, found among the Minimap's children because its button has no global name

### HUD layout (`/ftlayout`)

The layout is set by code through the Edit Mode API, not by dragging. The screen is about 2133 x 1200 UI units.

- From the bottom center up: the XP bar at y 0, the main action bar at y 19, bar 2 at 66 and bar 3 at 113.
- All three bars are one row of 12 icons. The main bar's art and scrolling are hidden.
- The stance bar sits left of bar 3, at x -301.
- BetterSwingTimer is at CENTER 0, -425. Pally Seal Cooldowns is at 0, -375.

A one-time login step (`ForeverTweaksDB.barsStacked`) also anchors bars 2 and 3 above the main bar in the active custom Edit Mode layout.

### Party frames (`/ftparty`)

- Raid-style party frames, 72 x 72 squares, in class colors (`raidFramesDisplayClassColor`), with no background.
- Stacked vertically to the left of the player portrait. The position is worked out from where `PlayerFrame` sits.
- Blizzard's **Sort by Role**: tank > healer > dps, and you sit alphabetically among the dps.
- Written straight into the saved Edit Mode layout (`C_EditMode.SaveLayouts`), then applied with `/reload`.
- Ran once per account automatically (`ForeverTweaksDB.partyRoleSort`).

**Taint warning.** On Forever, unit frame health values are "secret". Two things taint the secure party frames and cause "attempt to compare ... secret number value ... tainted by ForeverTweaks" errors:

- Opening or closing Edit Mode from addon code (`ShowUIPanel` / `HideUIPanel(EditModeManagerFrame)`).
- Giving the party frames a custom sort (`CompactPartyFrame:SetFlowSortFunction`).

A "you last" sort is therefore not possible without that error. `/ftlayout` still opens Edit Mode from code, so it can raise the same error now that raid-style party frames are on. A `/reload` clears it.

### Player frame numbers

Health and mana are shown as numbers (`statusText` 1, `statusTextDisplay` NUMERIC). This is set once (`ForeverTweaksDB.statusText`) and can be changed in Options > Interface.

### One-time setups

Each one runs once and records a flag in `ForeverTweaksDB`; delete the flag to run it again.

| Flag | Scope | What it did |
|---|---|---|
| `okfBack[char]` | Per character | One Key Fishing: K casts, Shift-K toggles fishing mode; removed Stand and Fish's macro; turned lures, container opening and the indicator on |
| `wpuiNav` | Account | Waypoint UI: off-screen navigator at a fixed 300% distance, dynamic distance off |
| `platyImport[char]` | Per character | Platynator: imports the Jamestone profile ([wago.io/xFmq0meO5](https://wago.io/xFmq0meO5)) through `Platynator.API.ImportString` |
| `detailsTheme[char]` | Per character | Details!: WoW Forever theme (see below) |
| `partyLayout[char]` | Per character | Party frame layout |
| `barsStacked` | Account | Action bar stacking |

The Details! theme:

- Window: the "WoW Interface" skin, 250 x 140, bottom right above the bags.
- Text: Friz Quadrata.
- Bars: 16 px, class-colored, Blizzard texture.
- Accent: Forever teal `#99e6f2` on the title and status bar, the same color Forever Quest Tint uses.
- Skips Details' first-run welcome window.

## Saved variables

`ForeverTweaksDB` (account-wide):

- `enabled`: whether quest automation is on.
- `icons`: positions of the wrapped minimap icons.
- `dump`: the output of `/ftdump`.
- The one-time flags above.

## Maintenance

- **Vanilla quest list:**
  - Run `python -I update_ids.py` after Forever Quest Tint updates, with the game closed (or `/reload` afterwards).
  - It reads Quest Tint's `VanillaQuests.lua` from the live AddOns folder.
  - If Quest Tint is not installed, it falls back to wago.tools: Classic Era QuestV2 IDs that also exist in Forever.
- **Syntax check before `/reload`:** `luajit -bl ForeverTweaks.lua`.
- **Saved variables:** the game rewrites them at logout. Edit them only while the game is closed; otherwise change settings at runtime.
